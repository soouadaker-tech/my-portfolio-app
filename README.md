# Portfolio – Soufiane Ouadaker

Next.js 14 (App Router) + Tailwind CSS 3, site statique.

## Lancer en local
    npm install
    npm run dev        # http://localhost:3000

## Modifier le contenu
Tout le texte est dans `data/profile.js`.
Photo : mets `photo.jpg` dans `public/` et remplace le bloc "SO" dans `components/Sidebar.js`.

## Déployer (gratuit)
- Vercel : push sur GitHub, puis "Import Project" sur vercel.com.
- Autre hébergeur : `npm run build` génère le dossier `out/` à envoyer tel quel.
